# ✨ Features

- 🤖 AI-generated interview questions
- 💬 Real-time AI feedback
- 📄 Resume-based interview preparation
- 🎯 Role-specific mock interviews
- 🧠 LLM-powered answer evaluation
- 📚 RAG-based knowledge retrieval
- 🔐 Secure authentication
- 📱 Responsive UI

# 🚀 Getting Started

```bash
git clone https://github.com/shivansh1609/AI-Powered-Interview-Assistant.git

cd AI-Powered-Interview-Assistant

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env.local`

```env
GEMINI_API_KEY=

DEEPGRAM_API_KEY=

PINECONE_API_KEY=

TAVILY_API_KEY=

OPENAI_API_KEY=
```
